# Портфолио Глеба Бобылькова

Статический сайт на [Astro](https://astro.build), перенесён из Design-канваса (вариант C): слева сайдбар, справа лента кейсов.

```bash
npm install      # один раз
npm run dev      # локально: http://localhost:4321
npm run build    # сборка в dist/
```

Нужен Node.js 22.22 или новее.

## Где что лежит

| Что | Где |
|---|---|
| Кейсы (каждый кейс — отдельный файл) | `src/content/cases/*.md` |
| Блоки компаний в ленте и пункты «опыт» | `src/content/companies/*.yaml` |
| Контакты, email, ссылка на CV, подпись в футере | `src/data/site.ts` |
| Картинки и видео | `public/media/<кейс>/…` |
| Общие стили, сетки, анимации, мобильная вёрстка | `src/styles/global.css` |
| Обложки-компоненты (карта, метрики Caveat, пометки маркером) | `src/components/covers/` |
| «Кое-что обо мне» и плейлист с пластинкой | `src/components/About.astro` |

Главная, меню «кейсы» и ссылка «Следующий кейс» собираются из файлов в `src/content/cases`, поэтому руками их править не нужно.

## Как добавить кейс

1. **Медиа.** Положите картинки и видео в новую папку `public/media/<slug>/`, например `public/media/profile/`.
2. **Файл кейса.** Скопируйте любой файл из `src/content/cases/` в `src/content/cases/<slug>.md`. Имя файла станет адресом страницы: `/cases/<slug>/`.
3. **Шапка файла (frontmatter).** Заполните поля:
   - `title` — короткое название для меню;
   - `company` — `sberhealth`, `dolyami` или `ozon`;
   - `year` и `order` — место в ленте и в меню;
   - `meta`, `heading` и `lead` — шапка страницы;
   - `card` — карточка на главной. В `card.cover.kind` выберите обложку: `image`, `video`, `doctor-metrics`, `map-slides` или `profile`.

   `draft: true` покажет на главной карточку с подписью «Кейс скоро» без страницы.
4. **Тело.** Ниже шапки идёт HTML кейса, как в канвасе: секции `<section id="…">` с `<h2>`. Пути к медиа пишите как `/media/<slug>/файл.webp`. Пункты «в этом кейсе» берутся из `toc`. Если `toc` не указать, они соберутся из секций автоматически. Проверьте результат через `npm run dev`.

Если вы переносите кейс из канваса, попросите Claude Code: «перенеси кейс CaseX из канваса в src/content/cases по образцу остальных».

## Выкладка в интернет (Vercel)

1. **GitHub.** Зайдите на github.com → New repository → назовите, например, `portfolio`. README не добавляйте. Затем в папке проекта выполните:
   ```bash
   git remote add origin https://github.com/<логин>/portfolio.git
   git push -u origin main
   ```
2. **Vercel.** Зайдите на vercel.com → Sign up with GitHub → Add New… → Project → Import репозитория `portfolio`. Astro определится сам, настройки не меняйте → Deploy. Через минуту сайт откроется по адресу вида `portfolio-xxx.vercel.app`.
3. **Дальше всё автоматически.** Каждый `git push` в `main` пересобирает сайт сам.

Тариф Hobby у Vercel бесплатный, карта не нужна.

### Домен

1. **Покупка.** Купите домен у российского регистратора с оплатой российской картой, например REG.RU, RU-CENTER (nic.ru) или Timeweb. Для `.ru` нужен паспорт: это требование для зоны.
2. **Подключение в Vercel.** Откройте проект → Settings → Domains → Add и введите домен. Vercel покажет DNS-записи: обычно это `A` для корня (`76.76.21.21`) и `CNAME` для `www` (`cname.vercel-dns.com`).
3. **DNS у регистратора.** В панели регистратора откройте «DNS-серверы и управление зоной», удалите старые `A`/`CNAME` для `@` и `www` и добавьте записи из Vercel. Обновление занимает от нескольких минут до суток. HTTPS Vercel включит сам.
4. **Адрес в проекте.** Впишите домен в `astro.config.mjs` (`site: 'https://ваш-домен'`) и сделайте `git push`. От этого адреса строятся canonical-ссылки и превью для соцсетей.
