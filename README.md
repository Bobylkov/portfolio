# Портфолио Глеба Бобылькова

Статический сайт на [Astro](https://astro.build), перенесён из Design-канваса (вариант C): слева сайдбар, справа лента кейсов.

Сайт: https://bobylkov.com (хостинг Timeweb Cloud App Platform, технический адрес https://bobylkov-portfolio-5b68.twc1.net).

```bash
npm install      # один раз
npm run dev      # локально: http://localhost:4321
npm run build    # сборка в dist/
```

Нужен Node.js 22.22 или новее (версия закреплена в `.nvmrc`).

## Где что лежит

| Что | Где |
|---|---|
| Кейсы (каждый кейс — отдельный файл) | `src/content/cases/*.md` |
| Блоки компаний в ленте и пункты «опыт» | `src/content/companies/*.yaml` |
| Контакты, email, ссылка на CV, подпись в футере | `src/data/site.ts` |
| Картинки и видео | `public/media/<кейс>/…` |
| Общие стили, сетки, анимации, мобильная вёрстка | `src/styles/global.css` |
| Обложки-компоненты (карта, метрики Caveat, пометки маркером) | `src/components/covers/` |
| «Кое-что обо мне» и плейлист с пластинкой | `src/components/About.astro` |

Главная, меню «кейсы» и ссылка «Следующий кейс» собираются из файлов в `src/content/cases`, поэтому руками их править не нужно.

## Как добавить кейс

1. **Медиа.** Положите картинки и видео в новую папку `public/media/<slug>/`, например `public/media/profile/`.
2. **Файл кейса.** Скопируйте любой файл из `src/content/cases/` в `src/content/cases/<slug>.md`. Имя файла станет адресом страницы: `/cases/<slug>/`.
3. **Шапка файла (frontmatter).** Заполните поля:
   - `title` — короткое название для меню;
   - `company` — `sberhealth`, `dolyami` или `ozon`;
   - `year` и `order` — место в ленте и в меню;
   - `meta`, `heading` и `lead` — шапка страницы;
   - `card` — карточка на главной. В `card.cover.kind` выберите обложку: `image`, `video`, `doctor-metrics`, `map-slides` или `profile`.

   `draft: true` покажет на главной карточку с подписью «Кейс скоро» без страницы.
4. **Тело.** Ниже шапки идёт HTML кейса, как в канвасе: секции `<section id="…">` с `<h2>`. Пути к медиа пишите как `/media/<slug>/файл.webp`. Пункты «в этом кейсе» берутся из `toc`. Если `toc` не указать, они соберутся из секций автоматически. Проверьте результат через `npm run dev`.

Если вы переносите кейс из канваса, попросите Claude Code: «перенеси кейс CaseX из канваса в src/content/cases по образцу остальных».

## Выкладка в интернет (Timeweb Cloud)

Код лежит на GitHub: https://github.com/Bobylkov/portfolio. Сайт собирает и раздаёт Timeweb Cloud App Platform: это российский хостинг, он открывается из России и принимает российские карты. Vercel тоже собирает сайт, но адреса `*.vercel.app` из России не открываются.

1. **Регистрация.** Зарегистрируйтесь на timeweb.cloud и пополните баланс российской картой. Цена фронтенд-приложения зависит от числа запросов, точная сумма видна в панели при заказе.
2. **Новое приложение.** App Platform → «Создать» → тип **Frontend** → **GitHub**. Разрешите Timeweb доступ к репозиторию `Bobylkov/portfolio` и выберите ветку `main`.
3. **Окружение и сборка.** Astro может не оказаться в списке фреймворков, тогда выберите любой статический вариант. Версия Node.js — 22 или новее. В «Расширенных настройках» укажите:
   - команда сборки: `npm ci && npm run build`;
   - директория сборки: `dist`;
   - путь до директории проекта оставьте пустым.
4. **Автодеплой.** Галочка «сборка по последнему коммиту» должна стоять. Нажмите «Заказать» и дождитесь конца лога сборки. Сайт откроется на техническом домене, который показан в настройках приложения.

После этого каждый `git push` в `main` пересобирает сайт сам.

### Домен

1. **Покупка.** Купите домен у российского регистратора: в самом Timeweb, REG.RU или RU-CENTER. Для `.ru` нужен паспорт — это требование для зоны.
2. **Привязка.** В приложении App Platform откройте «Настройки» → «Домены», добавьте домен и пропишите у регистратора DNS-записи, которые покажет Timeweb. Если домен куплен в Timeweb, записи пропишутся сами. Обновление DNS занимает от нескольких минут до суток. SSL-сертификат Timeweb выпустит сам.
3. **Адрес в проекте.** Впишите домен в `astro.config.mjs` (`site: 'https://ваш-домен'`) и сделайте `git push`. От этого адреса строятся canonical-ссылки и превью для соцсетей.

## Ассистент на сайте

Чат в правом нижнем углу отвечает без нейросети и внешних сервисов — всё считается в браузере посетителя.

- **База знаний** — [src/data/assistant.ts](src/data/assistant.ts): около 90 готовых ответов. У каждого есть примеры формулировок (`examples`) и ключевые слова (`keys`). Там же лежат темы (кейсы и компании), стороны кейса (проблема, исследование, решение, метрики, команда…) и словарь разговорных синонимов.
- **Как выбирается ответ** — [src/lib/assistant-search.ts](src/lib/assistant-search.ts):
  1. в вопросе ищутся тема и сторона: «карточка врача» + «метрики» → готовый ответ этой пары;
  2. если темы в вопросе нет, ассистент помнит тему прошлого ответа: «а метрики какие?»;
  3. если готового ответа нет, он ищет по текстам кейсов и показывает нужное место со ссылкой.
- **Как научить новому:**
  - добавьте ответ или примеры формулировок в `src/data/assistant.ts`;
  - если вопрос, на который ассистент ответил плохо, нужно запомнить, впишите его в `scripts/assistant-eval-set.ts` с правильным ответом.
- **Проверка качества:**
  ```bash
  npm run build && npm run eval:assistant
  ```
  - `-- --holdout3` — прогон на контрольном наборе;
  - `node scripts/assistant-ask.ts "вопрос"` — разбор одного вопроса.

Ответы с текстом «Об этом Глеб расскажет сам» (мотивация, сильные стороны, управление, выход на работу, неудачи, конфликты) ждут ваших ответов.
